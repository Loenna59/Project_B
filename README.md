# Party Banimals (Party Animals 모작)

> 프로젝트 기간: 2025.03.05 ~ 2025.04.03  
> 팀 규모: 3인  
> 사용 엔진: Unreal Engine 5 (C++ 및 Blueprint 병행)  
> 장르: 물리 기반 멀티플레이어 파티 격투 게임  

---

## 프로젝트 개요

`Project_B`는 인기 게임 **Party Animals**를 기반으로 제작된 모작 프로젝트입니다.  
귀여운 동물 캐릭터들이 다양한 맵에서 물리 기반 전투를 벌이는 구조로 설계되었으며,  
다양한 상호작용 요소와 멀티플레이어 환경에서의 게임 플레이를 중심으로 구현되었습니다.

---

## 주요 기능

| 기능 항목             | 설명                                                                 |
|----------------------|----------------------------------------------------------------------|
| 물리 기반 전투 시스템 | 캐릭터 간 충돌, 넉백, 리액션 등을 물리 엔진을 활용하여 구현               |
| 다양한 캐릭터        | 각기 다른 외형의 동물 캐릭터 선택 가능, 실시간 스킨 변경 기능 포함        |
| 맵 인터랙션 요소      | 블랙홀, 이동 플랫폼 등 동적 오브젝트와의 상호작용 가능                    |
| 멀티플레이어 모드     | 로컬 및 온라인 기반 멀티플레이어 지원, 개인전 및 팀전 모드 포함           |
| UI 및 HUD 구성        | 체력바, 타이머, 점수판 등 게임 진행을 지원하는 UI 요소 구현               |

## 기술적 구현 상세

### 물리 기반 전투 시스템

- 캐릭터 간 충돌과 피격 반응에 물리 엔진의 힘 적용
- 공격 시 넉백, 리액션 애니메이션 등 시각적 피드백 강화
- 물리 임펄스를 활용한 타격감 조절

### 캐릭터 시스템

- 다양한 외형의 동물 캐릭터를 선택 가능
- 런타임 중 스킨 및 메시 변경 기능 구현
- 애니메이션 및 본 구조 공유를 통한 최적화

### 맵 상호작용 기믹

- 블랙홀 생성 스킬 구현 (Niagara + RadialForce 사용)
- 맵 내 상호작용 가능한 오브젝트 배치 및 충돌 처리
- 이동 발판 등 실시간 플레이에 영향을 주는 기믹 존재

### 멀티플레이어 모드

- 로컬 및 네트워크 기반 멀티플레이 구현
- 팀 데스매치, 개인전 등 다양한 규칙 적용
- 서버/클라이언트 간 캐릭터 상태 동기화 처리

### UI 및 게임 진행 관리

- UMG를 이용한 체력바, 타이머, 스코어 보드 구성
- 게임 시작/종료 조건 제어 및 게임 모드 별 UI 관리
- 게임 진행 중 스코어 및 상태 실시간 반영

---

## 사용 기술

- **Unreal Engine 5**
- **C++ / Blueprint 혼합 구조**
- **Niagara Particle System** (블랙홀 등 특수 효과)
- **Physics Simulation** (물리 기반 충돌 및 넉백)
- **UMG** (UI 구성 및 HUD)
- **AIController / NavMesh** (적 추적 및 경로 이동)

---

## 회고 및 개선 사항

- 물리 엔진을 활용한 전투 시스템 구축 시 충돌 처리와 리액션의 **정밀한 튜닝**이 필요했음
- 멀티플레이어 모드 구현 중 **캐릭터 상태의 네트워크 동기화** 문제 해결을 위한 반복적인 테스트 진행
- 다양한 맵과 오브젝트를 안정적으로 동작시키기 위한 **트리거 및 인터랙션 로직 최적화**
- UI 시스템 개선을 통해 실시간 피드백 강화 및 **UX 품질 향상**

---

이 프로젝트는 **Party Animals**의 게임 메커니즘을 분석하고 재현하며,  
물리 기반 상호작용과 멀티플레이어 환경에서의 안정성 구현을 목표로 삼았습니다.
